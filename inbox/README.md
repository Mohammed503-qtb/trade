# 📥 inbox — صندوق الاستقبال المرئي

هذا المجلد ملكك بالكامل (ظاهر في متصفح الملفات، قابل للقراءة والكتابة).

**الغرض:** ضع هنا أي ملف تريد إيصاله إليّ — وأي ملف يصل يُلتقط تلقائيًا
خلال ثانيتين ويُؤمَّن في `received/` (صندوق دائم) مع سجل وصول موثق.

**لماذا لا مجلد upload القديم؟** هو نقطة تثبيت لسحابة تخزين تديرها المنصة،
مخفية من متصفحك بالتصميم، وقناة البوابة إليه معطوبة. هذا المجلد بديل محلي موثوق.
